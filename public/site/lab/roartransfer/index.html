03 · Safe

Only who has the link.

A transfer is not a public folder. It opens from its own link, and only for 3 days.

Kept private

Files are kept in private storage, not at a public address. Only you, or the people in the chat, can put files there.

A link nobody can guess

Each file gets its own random code. Without the link, nobody can find the file.

A fresh address for each download

Download gets a new address every time the page opens, good for one hour.

It expires on its own

After 3 days the link says the transfer has expired, and every hour RoarTransfer deletes what is older than that.

Only accounts send

Only people signed in to RoarMe can send a file. Downloading needs nothing.

05 · Questions

Good to know.

Is RoarTransfer free?

Yes. It comes with a RoarMe account, which is free too.

Does the person I send to need an account?

No. They open the link, see the file's name, size and expiry, and press Download. No account, no app.

How big can it be?

Up to 3 GB in one transfer, in one file or several together. Files are sent as they are, never made smaller.

How long does the link work?

3 days from when it was sent. Then the link says the transfer has expired and the file is deleted. If someone still needs it, send it again.

What if I send several files?

Each file gets its own link. Copy one, copy them all at once, share them, or put them straight into an email.

What if the connection drops?

RoarTransfer waits a little, asks how far the file got and goes on from there, a few times if it has to. On the web page, keep the page open until it says Sent.

I sign in to RoarMe with THEMADLIONS Hub. Can I use the page?

Yes. Sign in to RoarMe in the same browser first, then open RoarTransfer: it uses the same sign-in.
